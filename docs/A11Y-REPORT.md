# A11y-прогон

**Дата:** 09.11.2026  
**Статус:** пройден для текущего объёма; axe/скринридер — следующий уровень.

## Что проверено

### Ширины

- 320 px;
- 390 px;
- 720 px (эквивалент 200% zoom);
- 1024/1440 px — выборочно.

Страницы:

- лендинг;
- UI Kit;
- кабинет УК: инбокс, мои задания, объекты, паспорт, помещения,
  собственники, счётчики, импорт, квартиры и панель, привязки, профиль;
- новые разделы УК: сотрудники, полезные телефоны, журнал, отчёты —
  390/1440, overflow нет;
- приложение жителя: заявки, счётчики, профиль, гостевой вход,
  объявления, уведомления, документы; 320/390 без overflow.
- график расхода имеет текстовое описание для скринридера.

### Клавиатура и фокус

- Tab/Shift+Tab по формам, таблицам и Drawer/Modal.
- Enter/Space на кликабельных строках таблицы.
- Drawer/Modal: focus trap, Escape, возврат фокуса.
- Глобальный `:focus-visible` не убирается; на тёмном сайдбаре — лаймовый.

### Контраст и состояния

- «Прочитать все» в уведомлениях: был невидимый `var(--brand)`,
  заменён на `--brand-600` с весом 600.
- Ошибки — Alert с текстом, не только цветом.
- Статусы — Badge с текстовой подписью.
- Hover/focus строк таблиц.

### Найдено и исправлено

- профиль УК расширялся до 329 px на 320: нативные поля и grid-дети
  получили `min-width: 0`;
- кнопки действий в заявке растягивались под `ActionPanel`:
  `align-self: flex-start`, панель отдельной строкой;
- у собственников на 320 кнопки «Изменить/Убрать» вылезали за карточку:
  перенос на мобильном;
- логотип и подпись «кабинет УК» были одной ссылкой на лендинг:
  кликабелен только логотип, ведёт в кабинет;
- у поля файла импорта был нативный некрасивый контрол: заменён
  стилизованной кнопкой с скрытым input.

## Остаток

- axe-core/Playwright не запускались: в проекте нет настроенного
  браузерного a11y-набора.
- Реальный экранный диктор (NVDA/VoiceOver) не проверялся.
- Safari/iOS не проверялись.
- Нет автоматической проверки контраста всех токенов.

Это не блокеры текущего релиза, но следующие задачи качества.
