# Внедрение дизайн-системы Liviti

**Статус:** foundation завершён; компоненты и галерея готовы. Sidebar УК
перенесён в production; осталась постепенная миграция экранов.
**Дата:** 08.11.2026
**Основа:** Brand Book 1.0 + UI Kit 1.0 + текущая дизайн-система проекта.

## Что уже сделано

### Foundation

- `packages/ui/src/styles/tokens.css` — новые брендовые примитивы:
  `--liviti-ink`, `--liviti-green`, `--liviti-lime`, `--liviti-paper`.
- Старые имена `--brand-*`, `--text-*`, `--bg`, `--surface`, `--border`
  сохранены как алиасы. Поэтому существующие экраны не пришлось переписывать.
- `--text-secondary` и `--text-muted` затемнены до `#65736F`: это проходит
  AA на `#F5F7F3` и `#FFFFFF`. `--text-disabled` (`#87938E`) остался только
  для действительно неактивного текста.
- Статусы переведены на тёмные варианты цветов, чтобы цветной текст на
  пастельном фоне не проваливал контраст.
- Радиусы: 8 / 12 / 16 / 22 / 28 / pill.
- Тени: sm / md / lg; карточка по умолчанию без тени.
- `--focus`, `--duration-*`, `--control-height-*`, `--content-max-*`.

### Типографика

- Manrope и Inter подключены через `@fontsource-variable/*` в
  `packages/ui/src/styles/global.css` — шрифты лежат в бандле, без Google Fonts
  и без внешнего запроса в рантайме.
- `--font-heading` / `--font-body`; глобальные `h1–h4` используют Manrope.
- Шкала: Display 56, H1 32, H2 26, H3 21, H4 18, body 16, compact 15,
  secondary 13, caption 12.

### Компоненты

- `Button`: добавлены `size` (`sm`/`md`/`lg`), `outline`, `accent`,
  `leadingIcon`/`trailingIcon`; `compact` сохранён как совместимый вариант
  для УК. Основные кнопки — pill, компактные — 12 px.
- `Select`: нативный select с label, hint, error и ARIA-связями.
- `Checkbox`, `Radio`, `Switch`: доступные подписи, description, disabled;
  `Switch` — `role="switch"` + `aria-checked`.
- `Badge`: универсальный статусный бейдж с вариантами
  success/warning/danger/info/neutral.
- `Card`: базовая карточка, тень только по `elevated`.
- `ResidentShell` / `StaffShell`: два preview-каркаса на одних токенах.
  Житель — светлая бумага и карточки; УК — Deep Ink-сайдбар, плотная
  таблица и компактные действия. `StaffLayout` уже использует sidebar,
  Shells остаются эталоном для галереи.
- `Alert`, `Toast`, `Skeleton`: обратная связь и загрузка.
- `DataTable`: сортировка, выбор строк, плотность, мобильные карточки.
- `FilterBar`: поиск, селекты, сброс и счётчик найденного; на мобильном
  поля складываются в колонку.
- `Tabs`: tablist/tab/tabpanel, стрелки, Home/End.
- `Pagination`: страницы, ellipsis, aria-current.
- `Tooltip`: hover/focus, `role="tooltip"`, `aria-describedby`.
- `Drawer`: боковая панель для деталей, общий focus trap с Modal.
- `Popover`: контекстные действия, закрытие по клику вне/Escape.
- `Modal`: focus trap, Escape, возврат фокуса на триггер, размеры sm/md/lg,
  блокировка прокрутки фона.
- `Field`, `TextArea`, `StatusBadge`, `TicketCard` используются как есть;
  их стили подхватили новые токены.

## Принятые решения и остаток

1. **Синий УК vs зелёный Liviti.** Принято: синий убран, УК получил
   Deep Ink-sidebar и плотную навигацию.
2. **Pill-кнопки.** Принято: pill для жителя/лендинга, 12 px для компактных
   действий УК.
3. **Body 14/15/16.** Принято: житель 16, УК 15, таблицы 14.
4. **Статусы.** Принято: 8 названий, 5 цветовых вариантов, тёмный текст
   на пастельном фоне; цвет всегда дублируется текстом.
5. **Лендинг.** Принято: переведён на общие токены и шрифты; структура
   и тексты не переписывались. Осталась точечная полировка.
6. **Admin sidebar.** Сделан: `StaffLayout` использует sidebar 236 px на
   десктопе и мобильную шапку + нижнюю навигацию. UI Kit предлагал 248/72 —
   ширину можно уточнить позже по реальным экранам.
7. **Тёмная тема.** Не входит: в Brand Book/UI Kit её нет.

### Этап 5. Проверки

- Контраст, focus, клавиатура, 200% zoom, 320/360/390/768/1440.
- `prefers-reduced-motion`.
- axe/Playwright и визуальные скриншоты.
- CI — после появления workflow-scope у токена.

## Definition of Done для компонента

1. Default, hover, active, focus, disabled, loading (если применимо).
2. Error/empty (если применимо).
3. Desktop и mobile.
4. Длинный текст.
5. Клавиатура и focus-visible.
6. Контраст AA.
7. Реальные данные/фикстуры без ПДн.
8. Нет горизонтального overflow на 320–390 px.
9. Обновлены stories/галерея и docs.
10. Не ломает существующий API компонента без переходного слоя.
