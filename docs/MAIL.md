# Почта Liviti

**Статус на 09.11.2026:** корпоративная почта домена не активирована.

## Что проверено

- MX `liviti.ru` → `mx1.timeweb.ru` / `mx2.timeweb.ru`.
- SPF: `v=spf1 include:_spf.timeweb.ru ~all`.
- `_dmarc.liviti.ru` содержит строку, похожую на SPF, а не корректный
  DMARC-политику. Это нужно исправить до рассылок.
- `mail.liviti.ru` указывает на боевой сервер `198.51.100.10`, хотя MX —
  Timeweb. Для почты этот A-рекорд не используется, но лучше привести
  DNS в порядок.
- В домене **0 почтовых ящиков**. `office@liviti.ru` **не существует**.
- Timeweb Cloud API видит домен (`GET /api/v1/mail/domains/liviti.ru`
  возвращает `mailboxes: []`), но создание ящика
  (`POST /api/v1/mail/domains/liviti.ru`) возвращает **500**.
- Похоже, в аккаунте Timeweb не активирована услуга «Корпоративная
  почта» для домена. Панельного доступа к Timeweb в реестре нет — только
  API-токен, который видит домен.

## Планируемые ящики

- `office@liviti.ru` — общий ящик, связь и демо-заявки;
- `noreply@liviti.ru` — подтверждение e-mail и автоматические письма;
- `support@liviti.ru` — поддержка жителей;
- `news@liviti.ru` — рассылки и объявления.

Пароли — только DPAPI в `C:\Users\79237\.dsh\secrets\`, в репозиторий и
переписку не попадают.

## Что нужно для разблокировки

1. Включить корпоративную почту для `liviti.ru` в панели Timeweb
   (или дать доступ к панели/поддержке Timeweb).
2. После активации: создать ящики через API/панель, проверить SMTP,
   прописать конфигурацию на сервере.
3. Затем включить:
   - подтверждение e-mail кодом;
   - сброс пароля по e-mail;
   - отправку уведомлений/рассылок.
