# Фото объектов на главной

## Права

Фотографии ЖК «Наследие» и ЖК «Буревестник» предоставлены владельцем
проекта Liviti; заказчики не возражают против использования изображений
на сайте liviti.ru. Исходники не коммитятся — в репозитории лежат
оптимизированные WebP (качество 82).

## ЖК «Наследие», Барнаул

- `hero-nasledie-1920.webp` / `1280` / `800` — фасад, hero;
- `evening-nasledie-1200.webp` / `800` — вечерний фасад, редакционный блок;
- `gate-nasledie-800.webp` — въезд во двор, блок инфраструктуры;
- `autumn-nasledie-936.webp` — фасад осенью, карточка пилотного объекта;
- `parking-nasledie-1200.webp` — паркинг, блок деталей;
- `lobby-nasledie-1000.webp` — входная группа, блок деталей.

## ЖК «Буревестник», Барнаул

- `burevestnik-1600.webp` / `1200` / `800` — карточка пилотного объекта.

Нельзя подменять кадр «Наследия» или стоковым изображением ни один из
объектов.

## Проверенные внешние источники

- [ЖК «Наследие» — Всеостройке.рф](https://xn--b1agapfwapgcl.xn--p1ai/zhk/nasledie-stroitelnaja-perspektiva/)
- [ЖК «Буревестник» — Всеостройке.рф](https://xn--b1agapfwapgcl.xn--p1ai/zhk/burevestnik/)

Используем только подтверждённые названия, адреса и год сдачи. Проценты
готовности, цены и площадь не переносим на главную без отдельной проверки.

## Правила

- не использовать чужие референсы из Luma, Queen's, Mairen, CloudHome,
  VALD, Intelbras и подобные;
- не ставить фото одного объекта на карточку другого;
- не добавлять выдуманные цифры и отзывы;
- alt-текст описывает объект, а не украшает;
- ниже первого экрана — `loading="lazy"`, hero — preload и `fetchPriority`.
