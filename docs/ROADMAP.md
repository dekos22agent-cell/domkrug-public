## Чего сейчас не делаем

| Не делаем | Почему |
|---|---|
| **ЕСИА** | 3–6 месяцев, СМЭВ, КЭП; на пилоте личность подтверждает УК |
| **Выгрузка недвижимости из ЕГРН/ФНС** | Недоступна для нашей категории, источник истины — УК |
| **Свой биллинг** (расчёт начислений) | Огромный продукт; берём данные у УК или у ЕРЦ |
| **Счётчики, лифты, СКУД в реальном исполнении** | Пока заглушки на витрине. Нужен подрядчик и оборудование |
| **Мультирегиональность** | Сначала один город, одна-две УК |

## Критерии готовности к пилоту с реальными жителями

- [ ] Телефон подтверждён, привязка к квартире подтверждена УК
- [ ] Человек с двумя квартирами видит обе
- [ ] Фото к заявке загружается и открывается у исполнителя
- [ ] Уведомление о смене статуса приходит без захода в приложение
- [ ] Деньги: начисление, оплата, реестр для УК — сходятся
- [ ] HTTPS на своём домене, cookie `Secure`
- [ ] Политика обработки ПДн опубликована, согласие фиксируется в аудите
- [ ] Бэкап базы проверен восстановлением, а не только созданием
- [ ] RLS включён: УК физически не может прочитать чужие данные
- [ ] Демо-данные удалены, реальные УК заведены через сид с их данными
